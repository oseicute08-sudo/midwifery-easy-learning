# Midwifery Easy Learning Center

**Learn. Practice. Become a Confident Midwife.**

A modern, mobile-first educational web application for midwifery and nursing students.

## Founder
Bismark Owusu

## Inspired by
Christabel Anderson

## Features

- **Home Dashboard** — Continue learning, stats, quick access
- **Courses** — Level 100 First Semester 2026/2027 curriculum structure
- **Lessons** — Structured content with Key Points, Clinical & Midwifery connections
- **Quiz Center** — Separate major section with MCQs, feedback, scoring
- **Midwifery Dictionary** — Searchable terms with clinical & midwifery relevance
- **Progress** — Lessons, quizzes, streaks, achievements
- **Profile** — Demo student profile + light/dark mode
- **Responsive** — Mobile bottom nav + desktop sidebar
- **Light & Dark mode**

## Tech

- React 19 + Vite
- React Router
- CSS custom properties (light/dark)
- LocalStorage for progress (ready for future auth/sync)

## Run

```bash
npm install
npm run dev
```

## Curriculum note

Course list is based on the B.Sc. Midwifery Level 100 First Semester registration form (Nursing and Midwifery Training College, Dunkwa-On-Offin). The detailed lesson structure for BND 101 is the learning pathway for this application.
